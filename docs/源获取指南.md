# 源获取指南

一句话：**tjtv 自己不带内容，它只是个播放器。内容来自「采集站」，采集站要你自己找。**

---

## 一、先搞懂原理

整个链路是这样的：

```
tjtv（播放器）  →  采集站（苹果CMS 接口）  →  真实视频（m3u8 直链）
     ↑                    ↑                        ↑
  你这个项目         要你提供的地址            采集站自己维护
```

采集站是别人搭的影视资源聚合站，会开放一个标准接口：

```
https://站点地址/api.php/provide/vod?ac=videolist&wd=关键词&pg=1
```

返回 JSON，里面 `list[]` 的每条记录带 `vod_name`（片名）、`vod_pic`（封面）、
`vod_play_url`（播放地址，格式是 `第1集$http://...m3u8#第2集$http://...m3u8`）。

**tjtv 要的就是这个「站点地址 + /api.php/provide/vod」。** 填进去就能搜能看。

## 二、怎么找源

### 途径 1：搜索引擎（最直接）

搜索关键词：

```
苹果CMS 采集站 接口 汇总
苹果cms v10 采集源 列表
免费采集接口 api.php/provide/vod
```

一般能搜到博客整理的清单，通常几十个地址。**别全信**，大部分是死的，用下面的工具筛。

### 途径 2：看别人搭的影视站

网上那些免费影视站，很多是苹果CMS 搭的。看它的接口路径：

- 打开站点，搜索一个片名，按 F12 看网络请求
- 找 `api.php/provide/vod` 这种请求，那个域名就是源
- 或者直接猜：`站点域名 + /api.php/provide/vod`

### 途径 3：找现成的订阅列表

搜 `LibreTV 源 订阅 json` 或 `TVBOX 配置 接口`，能找到别人维护的源列表。
tjtv 支持 TVBOX 配置格式，但**只有 `type:1` 的 JSON 接口能导入**，
Spider 类（`csp_*` / `.jar` / `.js`）需要 TVBOX 自己的引擎，导入不了。

### 途径 4：Telegram / 论坛

各种影视资源群、NAS 论坛经常有人分享接口地址。搜 `采集站 分享`。

## 三、怎么判断源能不能用

**别凭感觉填。** 用自带的体检工具：

```bash
python3 scripts/probe.py
```

它会并行测 16 个候选源，输出三种结果：

| 状态 | 含义 |
| --- | --- |
| **可播放** | 能搜到内容 + 能拿到 m3u8 直链 → 可以直接用 |
| **有地址** | 能搜到，但播放地址不是 m3u8（可能是 MP4 或需要爬详情页）→ 不一定能播 |
| **FAIL** | 连不上 / 被墙 / 接口废弃 |

换关键词测（有些源冷门片子没收录）：

```bash
python3 scripts/probe.py -k 流浪地球
```

测自己的清单：

```bash
# 先建个文件 mysources.txt，每行「名称|接口地址」
python3 scripts/probe.py -f mysources.txt
```

导出可用的源：

```bash
python3 scripts/probe.py -o app/data/probe-result.json
```

## 四、把源加进 tjtv

### 网页加（最简单）

1. 打开 `http://localhost:8021/tjtv`
2. 填名称 + 接口地址
3. 点「添加」——**会自动探活**，连不上直接拦下

### 接口加（批量/自动化）

```bash
curl -X POST http://localhost:8021/api/tjtv/sources \
  -H "Content-Type: application/json" \
  -d '{"name":"某某源","url":"https://example.com/api.php/provide/vod"}'
```

### 直接改文件（批量导入）

编辑 `app/data/tjtv-sources.json`：

```json
{
  "version": 1,
  "sources": [
    { "key": "s1", "name": "源A", "url": "https://a.com/api.php/provide/vod", "enabled": true },
    { "key": "s2", "name": "源B", "url": "https://b.com/api.php/provide/vod", "enabled": true }
  ]
}
```

重启服务生效。

## 五、源失效了怎么办

**这是常态，别慌。** 采集站经常换域名、关站、加验证。三个办法：

1. **多备几个源** —— 内置 5 个就是这意思，一个挂了还有其他
2. **重新体检** —— `python3 scripts/probe.py` 看哪些还活着，把死的删掉
3. **换域名不换站** —— 很多站是同一批资源换域名。比如接口里带 `bdzy`（百度资源）、`wolong`（卧龙）这类字样，搜这个名字往往能找到新域名

tjtv 首页搜索是**多源并行**的，一个源挂了不影响其他源的搜索结果，会在结果里标出来。

## 六、注意事项

### 合规

- 采集站的内容是第三方提供的，**合法性由采集站负责**，tjtv 只是播放器
- 自用没问题，**别公开传播**、别做商业用途
- 公网部署务必加密码 + HTTPS

### 安全

- `/api/tjtv/sources` 接口**不需要登录**，只在内网用
- 要暴露到公网，前面必须套一层带认证的反向代理
- 别随便填来路不明的地址，服务端会去请求它

### 稳定性

- 内网自建源（NAS 上的 IPTV）默认会被 SSRF 防护拦截，要额外加 `LIVE_ALLOW_PRIVATE=1`
- 采集站一般有频率限制，别写脚本猛刷
- 搜索结果有 60 秒缓存，同一关键词短时间重复搜不会重复打上游
